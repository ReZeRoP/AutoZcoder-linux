Waiting for the gateway

Your workspace will open when the verified gateway is available. Check the service status or start the service in the bar above.

  • Independent service

    Closing this window leaves the gateway running. Stopping the service disconnects API clients.

  • Verified connection

    No unrelated listener is adopted. Your dashboard edits are retained, and account actions are never replayed.

  • Autostart is optional

    Login autostart lives in the Service menu. Disabling it only changes future user-manager startup.

User manager unavailable? Run autozcoder serve in a terminal, then attach with autozcoder ui --config PATH. Custom configurations are attach-only and never manage the default unit.
